## Models and ModelLab

BugTraceAI publishes security-focused checkpoints in the **CORE-Fast**, **CORE-Pro**, **CORE-Ultra** and **Apex** families. Browse their [model cards](https://huggingface.co/BugTraceAI) for formats, requirements and license terms. The suite also supports external model providers according to each component's configuration. **ModelLab**, available through WEB, benchmarks selected OpenRouter models and helps review their results and costs. See each module's documentation for current provider support.

## Start Here

1. [Watch the DEF CON 34 demo](https://www.youtube.com/watch?v=FCoQNgO8hmM) to see the workflow end to end.
2. [Explore a real report](https://demo.bugtraceai.com/bugtraceai) generated against the BugStore practice target.
3. [Choose your modules with the Launcher](https://github.com/BugTraceAI/BugTraceAI-Launcher) or run a component independently.
4. [Read the documentation](https://github.com/BugTraceAI/BugTraceAI#documentation) for installation and component guidance.
5. [Ask questions in GitHub Discussions](https://github.com/BugTraceAI/BugTraceAI/discussions) or [report a problem in the affected repository](https://github.com/BugTraceAI/.github/blob/main/SUPPORT.md).
6. [Join the Discord community](https://discord.gg/g48NcdGme) for demos, feedback, and project discussion.
